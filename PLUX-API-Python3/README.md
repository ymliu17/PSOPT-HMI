# Bundled PLUX Python API binaries

These are the native driver files supplied with the existing PSOPT-HMI project.
Choose a directory matching the operating system, Python minor version, and
interpreter architecture; the controller selects its directory automatically.

- `M1_311`, for example, is for Apple Silicon Python 3.11.
- `MacOS/Intel310` is for Intel Mac Python 3.10.
- `Win64_310` is for Windows x64 Python 3.10.
- The Linux files are provided as supplied; architecture-specific Linux
  configurations may require adjusting the controller's driver selection.

Upstream source and setup guidance:
[pluxbiosignals/python-samples](https://github.com/pluxbiosignals/python-samples).
An upstream repository license copy is retained under
[`packaging/windows/third_party`](../packaging/windows/third_party/PLUX-python-samples-LICENSE.txt).

On macOS, the Bluetooth helper `bth_macprocess` must be executable and macOS
must permit the trusted native library and helper to run. Native binary files
are not generated by this project's build script.
